# Suraj Meena — Portfolio Rebuild

> Production-ready, fully editable creative developer and visual editor portfolio rebuilt from Framer.

---

## ⚡ Quick Start

### 1. Requirements
- **Node.js**: v18.18.0 or newer (v22+ recommended)
- **NPM**: v9+

### 2. Installation
```bash
npm install
```

### 3. Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Production Build & Verification
```bash
npm run build
npm run lint
```

## 🛠️ Stack Overview
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Vanilla CSS with CSS Modules & centralized design tokens
- **Motion**: Motion for React (`motion`) & GSAP
- **Icons**: Lucide React
- **Target Deployment**: Vercel
